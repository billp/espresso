# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Development workflow

Edit source files in `mmctl/`, then rebuild and reinstall:

```bash
python3 build.py   # bumps patch version, regenerates install.sh
bash install.sh    # installs to ~/.local/bin/espresso
```

Syntax check (what CI runs):

```bash
python3 -m py_compile mmctl/mm.py mmctl/mmctl.py
bash -n install.sh
```

There are no automated tests beyond syntax validation.

## Architecture

The project ships as a **single bundled Python script** (`~/.local/bin/espresso`) generated by `build.py` from two source files:

- `mmctl/mm.py` — daemon: moves the mouse via CoreGraphics (ctypes), checks lock state via `ioreg`, and respects a schedule (time window + day-of-week filter)
- `mmctl/mmctl.py` — TUI manager: hand-built ANSI/escape-code UI, no third-party libraries

### Two-mode bundle

`build.py` merges both files into one Python script. At runtime:

```python
_DAEMON_MODE = '--daemon' in sys.argv
```

- `--daemon` → runs `_daemon_main()` (the mouse mover loop)
- no flag → runs `_manager_main()` (the TUI)

The TUI spawns itself with `--daemon` via `nohup` to start the background process. It detects the running daemon by scanning `ps aux` for its own script name + `--daemon` flag.

### Build-time transformations (`build.py`)

- Strips shebangs, docstrings, top-level `import` statements, and `if __name__ == '__main__'` guards from both sources
- **Replaces `find_mm_processes()`** in the manager with `BUNDLE_FIND_MM` — a version that detects the daemon by the `--daemon` flag rather than by script filename
- **Replaces the `launch_mm` args** from `[sys.executable, MM_PY, ...]` to `[sys.executable, SCRIPT_SELF, '--daemon', ...]`
- Wraps manager code in `if not _DAEMON_MODE:` so its imports and globals don't execute in daemon mode
- Bumps the patch version and embeds it as `__version__`

### Config persistence

User settings (schedule, active days) are stored in `~/.config/espresso/config.json`. Interval and lock-only mode are passed as CLI args to the daemon process and are not persisted to the config file.

### TUI rendering

The TUI does full-screen redraws using ANSI escape codes (`\033[2J\033[H`). `vlen()` / `rpad()` strip ANSI codes when computing visual string widths for box layout. Raw terminal mode (`tty.setraw`) is used for keypress handling; `read_key()` decodes arrow keys from their escape sequences.

### Key invariant

`mmctl/mm.py` and `mmctl/mmctl.py` are the **source of truth**. `install.sh` is generated — never edit it directly.
